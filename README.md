# Machine Learning for IPMVP-Compliant Energy Savings Verification

A reproducible workflow for building energy baseline modelling, counterfactual prediction, and IPMVP-compliant savings verification.  
This repository demonstrates how to quantify energy savings using machine‑learning models that account for weather, occupancy, and operational variability.

---

## 📌 Overview

When an energy‑efficiency system or control strategy is deployed in a building, stakeholders ask:

> **"How much energy did this intervention actually save — and can you prove it?"**

Simple before/after bill comparisons are unreliable because energy use varies with:

- **Weather** (temperature, humidity, solar gain)
- **Occupancy** (weekends, holidays, seasonal patterns)
- **Operational changes** (equipment schedules, new devices)

To answer this rigorously, this project follows the  
**International Performance Measurement and Verification Protocol (IPMVP)** — the global standard for energy‑savings verification.
